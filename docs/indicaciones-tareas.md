# Indicaciones para generar las tareas

1. La primera tarea de implementación es la prueba de concepto del plan: verificar con una hoja real de Google Sheets que el navegador puede leer el CSV publicado y que las fotos de Drive se muestran.
2. Marca claramente las tareas que debo hacer yo manualmente, como crear y publicar la hoja de Google Sheets o probar en un celular real.
3. Cierra cada historia con una tarea de verificación manual de sus escenarios de aceptación, según quickstart.md.
